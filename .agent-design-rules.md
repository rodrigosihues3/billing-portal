# Directrices de Diseño y Frontend para el Agente

## Principios Estéticos
1. **Modo Claro Predeterminado:** La aplicación debe iniciar con fondo blanco/slate-50 limpio, con contraste tipográfico alto y bordes finos (1px en borders slate-200/slate-300).
2. **Modo Oscuro Sobrio:** Solo se activa con la clase `.dark`. Prohibido usar negros puros o tonos saturados de neón; usar zinc o slate neutral (slate-900 / slate-950).
3. **Prohibido el Estilo Genérico de IA:**
   - No usar gradientes púrpuras, violetas o efectos glassmorphism pesados.
   - No usar tarjetas flotantes con sombras desproporcionadas.
   - Emplear diseño editorial o SaaS B2B tipo Stripe o Vercel: bordes precisos, tipografía tabular (`font-mono`) para números, métricas y códigos de transacción, e iconos delineados con Lucide React (grosor 1.5px o 1.75px).
4. **Comportamiento Responsivo:** Mobile-first real, interfaces táctiles accesibles.

## Reglas de Negocio a Respetar
- La landing debe mostrar primero: Hero -> Métricas -> Planes (Starter S/ 99, Growth S/ 199, Enterprise S/ 399) -> Módulos explicativos -> Footer corporativo.
- Validaciones estrictas: Celular peruano (9 dígitos, inicia en 9), OTP de Yape (6 dígitos), tarjeta (16 dígitos), expiración temporal comprobada contra año/mes actual.
